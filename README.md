# edible-inedible-v.1

Игра **«Съедобное — несъедобное»** на чистом HTML/CSS/JS.

## Что умеет

- **Лендинг**: `index.html`
- **Игра**: `game.html`
- **5 уровней**, ускорение сложности
- **Комбо** и **бонусы**
- **Рекорд** сохраняется в `localStorage`

## Запуск

Просто открой `index.html` в браузере.

Если хочешь сразу стартовать игру без меню:

- `game.html?autostart=1`

## Структура

```
/
  index.html
  game.html
  assets/
    game.css
    game.js
    landing.js
```
